## 🐛 FIX COMMON ISSUES - TROUBLESHOOTING TITAN

</div>

<div align="center">
Error	Cause	Solution - Fix
`GROQ_API_KEY missing`	.env not set	Check .env file, ensure key starts with `gsk_` and no spaces
`Rate limited 429`	Groq free 30 req/min	Wait 60 seconds, or upgrade to Groq paid, or switch to FAST model
`Cannot find module`	npm install failed	Delete node_modules + http://package-lock.json, run `npm install` again
`Port 3000 in use`	Another app using port	Change PORT in .env to 3001, or kill process: `npx kill-port 3000`
`Streaming not working`	Old browser	Use Chrome latest, Firefox, not UC Browser old version
`Upload failed`	File too big >10MB	Reduce file size, split PDF, or increase limit in src/routes/upload.js
`Render: IP Ban?`	WhatsApp bot IP ban	Xiong Ai Groq API is NOT banned on Render. For WhatsApp bot, use proxy: `https://proxy.com`
`CORS Error`	Frontend not connected	Check http://server.js cors origin: `'*'` and ensure frontend fetch to `/chat` not full URL
`Memory full`	100 chats saved	Export via /export then clear localStorage: `localStorage.clear()`
`Logo not showing`	http://logo.png missing	Create http://logo.png in public/ - Use generated X logo from Xiong Ai
*Still stuck? Ask Xiong Ai itself: "How to fix Groq API error 429 on Render?"*
